# AI Flappy Bird

This project implements a Flappy Bird game with AI-controlled gameplay using Q-learning.

## Features
- AI gameplay using Q-learning
- Dynamic pipe generation and collision detection
- Real-time score tracking and generation display

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/ai-flappy-bird.git
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the game:
   ```bash
   python src/main.py
   ```

## Project Structure
- `src/`: Contains game logic, AI logic, configuration, and utilities
- `assets/`: Stores game assets such as images
- `tests/`: Unit tests for game components
